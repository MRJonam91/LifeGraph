# Security Policy — LifeGraph

## 🇮🇹 Segnalare una vulnerabilità
- **Non aprire una issue pubblica.** Usa *Security → Report a vulnerability* (GitHub Security Advisory) oppure scrivi a fbxmano@gmail.com.
- Includi: descrizione, passi per riprodurre, versione e file LifeGraph di esempio coinvolto (con dati sensibili e PII anonimizzati).
- Risposta entro **7 giorni**; divulgazione coordinata entro **90 giorni** dalla segnalazione.

## 🇬🇧 Reporting a vulnerability
- **Do not open a public issue.** Use *Security → Report a vulnerability* (GitHub Security Advisory) or email fbxmano@gmail.com.
- Include: description, steps to reproduce, version, and sample LifeGraph file (with PII and sensitive tokens anonymized).
- Response within **7 days**; coordinated disclosure within **90 days** of the report.

## Versioni supportate / Supported versions
Solo l'ultima minor release. / Latest minor release only.
